What is CASTER?

CASTER is a token project on BNB Smart Chain. This website provides an interface to explore its contract, supported market information and Web3 wallet interactions.

CASTER uses BNB Smart Chain mainnet, Chain ID 56. The token contract address is 0x848e975518d8E95e0748D725696Ab2d0521e649E.

How can I add CASTER to MetaMask?

Connect a compatible wallet, select BNB Smart Chain and click Add Token. Your wallet will ask for permission before adding the token information.

Where can I trade CASTER?

The trading buttons open PancakeSwap with the CASTER contract selected. Trading depends on liquidity availability and support for the token.
