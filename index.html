FREQUENTLY ASKED QUESTIONS.

What is CASTER?

CASTER is a token project on BNB Smart Chain. This website provides access to its token information, wallet integration and supported decentralized market services.

Which blockchain does CASTER use?

CASTER uses BNB Smart Chain mainnet, Chain ID 56.

How do I add CASTER to MetaMask?

Connect your wallet and click Add Token. Your wallet will request permission to add the token contract.

How can I trade CASTER?

Use the trading section to open PancakeSwap with the CASTER contract selected. Trading requires a supported liquidity pool.

Has the token been audited?

No independently verified audit report is presented on this website. Always research the token contract before transacting.
